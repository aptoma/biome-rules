# Agent Guidelines

## Commits and pull requests

- This repository is public. Do not name or reference other projects, repositories, customers, or internal systems in commit messages or pull request descriptions, unless the project is a public dependency or source this package builds on (such as Biome or anti-slop).
- Describe changes in terms of this package: the rules, the preset, and their behavior.

## Verification

- Run `npm test` (lint, type check, and rule tests) before committing.
